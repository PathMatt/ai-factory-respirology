# Pneumoconiosis of Intelligence — Matt Cecchini, MD (respirology, 15–20 min)
Static 16:9 HTML deck: `index.html` + `assets/` (no build step). Slides are lifted from Camp Pods, the biomarker deck and CAP26; the Camp Pods modules run unmodified (`deck.js` fires `deck-slide-change` and toggles `[hidden]`). On Vercel, `/api/*` is rewritten to the Camp Pods API for the live Jev demos. To test locally with that rewrite: `python3 qa/serve.py 8765`.
